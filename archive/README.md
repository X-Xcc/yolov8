# 长明灯项目归档

本目录保存 2026-10-09 项目封版所需的审计记录和可复现资产。

## 内容

- `2026-10-09/长明灯_归档审计报告_2026-10-09.md`：封版审计报告。
- `2026-10-09/长明灯_全量文件SHA256_2026-10-09.csv`：原始项目目录全量文件清单。
- `2026-10-09/资产归档清单.json`：本仓库 LFS 归档的大小和 SHA-256。
- `assets/dataset-*.tar`：训练数据集，保持原始相对目录结构。
- `assets/training-results-and-models.tar`：训练运行结果、最终权重、COCO8 样例和基础权重。

## 恢复

1. 安装 Git LFS 后克隆仓库并执行 `git lfs pull`。
2. 在仓库根目录执行：

   `tar -xf archive/assets/dataset-actions.tar`

   对其余四个归档重复执行。
3. 使用 `archive/2026-10-09/资产归档清单.json` 校验归档 SHA-256。
4. 按根目录 README 安装依赖，先用离线样例验证，再连接真实摄像头。

真实 `.env`、摄像头密码、JWT 密钥、运行数据库、依赖缓存和构建缓存不进入公开 Git。它们不属于源码复现资产，原始位置已记录在全量文件清单中。
